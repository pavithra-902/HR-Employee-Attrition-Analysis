# HR Employee Attrition Analysis & Dashboard

## 📌 Project Overview

This project analyzes employee attrition using an HR dataset and presents the findings through an Excel dashboard.

The objective is to understand employee attrition patterns across different employee characteristics and workplace factors.

## 🛠️ Tools Used

* Microsoft Excel
* Pivot Tables
* Excel Charts
* Data Cleaning & Transformation
* Data Analysis

## 📂 Dataset

The dataset contains **1,470 employee records and 35 columns** covering employee demographics, job information, compensation, satisfaction, work conditions, and attrition.

The original dataset is available in the `Dataset` folder.

The analyzed working file is available in the `Working Dataset` folder.

## 📊 Key KPIs

* **Total Employees:** 1,470
* **Employees Left:** 237
* **Employees Stayed:** 1,233
* **Overall Attrition Rate:** 16.12%

## 🔍 Analysis Performed

The analysis examines attrition across:

* Department
* Overtime
* Job Role
* Age Group
* Tenure Group
* Business Travel
* Work-Life Balance

Attrition rates were calculated using Pivot Tables and summarized in the dashboard.

## 📈 Dashboard

The Excel dashboard contains KPI cards and charts to provide a clear overview of employee attrition patterns.

### Dashboard Highlights

* Attrition Rate by Department
* Attrition Rate by Overtime
* Attrition Rate by Job Role
* Attrition Rate by Age Group
* Attrition Rate by Tenure Group
* Attrition Rate by Business Travel
* Attrition Rate by Work-Life Balance
